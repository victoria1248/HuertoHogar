# HuertoHogar
Bienvenido al proyecto HuertoHogar 

HuertoHogar es un sitio web que presenta una propuesta de marca vinculada con los productos frescos, el apoyo a productores locales y el cuidado del medioambiente. Su contenido combina categorías de productos, información institucional, publicaciones y formularios para representar la experiencia de una plataforma de comercio electrónico.

El proyecto organiza su contenido en páginas independientes y separa la estructura HTML, los estilos CSS, la lógica JavaScript y los recursos gráficos. Esta distribución facilita la lectura del código y el mantenimiento de cada sección.
